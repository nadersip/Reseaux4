Configuration de Base

Définir l’identité de l’équipement et sécuriser l’accès

hostname NOM
enable secret [votre_mot_de_passe]
no ip domain-lookup

Configurer l’accès console (accès local)

line console 0
 password [mot_de_passe_console]
 login
 logging synchronous
 exec-timeout 0 0
exit

Configurer l’accès distant (Telnet/SSH via VTY)

line vty 0 15
 password [mot_de_passe_vty]
 login local
exit

Sécuriser les mots de passe et afficher un message légal

service password-encryption
banner motd #AUTHORIZED ACCESS ONLY#

Configurer la passerelle par défaut (gestion du switch)

ip default-gateway IP_ROUTER

Vérifier l’état des interfaces et la configuration

show ip interface brief
show running-config

Router-on-a-Stick (Routage Inter-VLAN)

Configuration du switch

! Créer les VLANs
        vlan [NUM_VLAN]
        name [NOM_VLAN]

        Configurer les ports VLAN (mode access)
        interface [INTERFACE_ACCESS]
        switchport mode access
        switchport access vlan [NUM_VLAN]

        Configurer le trunk vers le routeur
        interface [INTERFACE_TRUNK]
        switchport mode trunk
        switchport trunk native vlan [VLAN_NATIVE]
        switchport trunk allowed vlan [NUM_VLAN1],[NUM_VLAN2]

Configuration du routeur

Interface physique connectée au switch
        interface [INTERFACE_PHYSIQUE]
        no shutdown

        Créer des sous-interfaces pour chaque VLAN
        interface [INTERFACE_PHYSIQUE].[NUM_VLAN]
        encapsulation dot1Q [NUM_VLAN] [NATIVE si applicable]
        ip address [IP_VLAN] [MASQUE_VLAN]

        Activer le routage
        ip routing

Vérifications

show vlan brief
        show interfaces trunk
        show ip interface brief

DHCP et IP Helper

Configuration du serveur DHCP sur le routeur

Définir le pool DHCP
        ip dhcp pool [NOM_POOL]
        network [RESEAU] [MASQUE]
        default-router [IP_PASSERELLE]
        dns-server [IP_DNS]

        Exclure certaines adresses du pool
        ip dhcp excluded-address [IP_DEBUT] [IP_FIN]

Configurer IP Helper pour relayer les requêtes DHCP sur un autre réseau

interface [INTERFACE]
        ip helper-address [IP_SERVEUR_DHCP]

Vérification

show ip dhcp binding
        show running-config

Gestion du Réseau

Activer CDP pour découvrir les appareils Cisco voisins

cdp run

Désactiver CDP sur l’équipement

no cdp run

Vérifier les voisins et interfaces CDP

show cdp
show cdp neighbors
show cdp neighbors detail
show cdp interface

Activer LLDP pour découvrir les appareils de différents fabricants

lldp run

Vérifier les voisins LLDP

show lldp
show lldp neighbors
show lldp neighbors detail

NTP (Network Time Protocol)

ntp server IP_Serveur

Vérifier la synchronisation de l’heure

show clock detail
show ntp associations
show ntp status

Syslog (Journalisation des événements)

logging [IP_serveur_syslog]
service timestamps log datetime msec 
logging trap debugging
logging on

Routage Statique

Destination via interface de sortie

ip route [RESEAU] [MASQUE] [INTERFACE_SORTIE]

Route statique recursive

ip route [RESEAU] [MASQUE] [NEXT_HOP]

Vérification

show ip route

ACL – Access Control Lists

ACL standard numérotée

access-list [NUM] [permit | deny | remark [TEXTE]] [HOST|RESEAU] [wildcard]

ACL standard nommée

ip access-list standard [NOM_ACL]
 remark [DESCRIPTION]
 permit | deny [HOST|RESEAU] [wildcard]
 deny any
exit

ACL étendue numérotée

access-list [NUM] [permit | deny | remark [TEXTE]] [PROTOCOLE] [SOURCE] [WILDCARD] [PORT] [DESTINATION] [WILDCARD] [PORT] [established]

ACL étendue nommée

ip access-list extended [NOM_ACL]
remark [DESCRIPTION]
permit | deny [PROTOCOLE] [SOURCE] [WILDCARD] [PORT] [DESTINATION] [WILDCARD] [PORT] [established]
deny ip [SOURCE] [DESTINATION]
exit

Appliquer sur interface

interface [INTERFACE]
 ip access-group [NUM] ou [NOM_ACL] [in | out]

Sécuriser les lignes VTY avec ACL

line vty 0 4
login local
transport input [telnet | ssh]
access-class [ACL_VTY] in

Supprimer

no ip access-list [standard | extended ] [NUM | NOM_ACL]

Vérification

show access-lists
show ip interface [INTERFACE] | include access list

Routage Dynamique – OSPF

Activer OSPF et définir le Router ID

router ospf [PROCESS_ID]
router-id [ROUTER_ID]

Annoncer des réseaux dans OSPF

network [RESEAU] [WILDCARD] area [AREA_ID]

Via interface

interface [INTERFACE]
 ip ospf [PROCESS_ID] area [AREA_ID]

Interfaces passives

passive-interface [INTERFACE]

Interfaces passives sur toutes les interfaces

passive-interface default

Propagation d’une route statique

default-information originate

Effacer le processus OSPF

clear ip ospf process

Vérification OSPF

show ip ospf neighbor
show ip protocols
show ip ospf
show ip ospf interface

NAT

NAT statique

ip nat inside source static [LOCAL_IP] [GLOBAL_IP]

NAT dynamique

ip nat pool [NOM_POOL] [IP_DEBUT] [IP_FIN] netmask [MASQUE]
access-list [NUM] permit [RESEAU_INTERNE] [WILDCARD]
ip nat inside source list [NUM ou NOM_ACL] pool [NOM_POOL] [overload]

PAT (NAT surcharge) avec interface

ip nat inside source list [NUM ou NOM_ACL] interface [INTERFACE_EXTERNE] overload

Définir les interfaces internes et externes

interface [INTERFACE_INTERNE]
 ip nat inside
interface [INTERFACE_EXTERNE]
 ip nat outside

Vérification NAT

show ip nat translations
show ip nat statistics

Tunnel GRE

Configurer le tunnel sur le Router 1

interface Tunnel0
            ip address [TUNNEL_IP_ROUTER1] [MASQUE]
            tunnel source [INTERFACE_PHYSIQUE_WAN]
            tunnel destination [IP_PUBLIQUE_ROUTER2]
            tunnel mode gre ip

Configurer le tunnel sur le Router 2

interface Tunnel0
            ip address [TUNNEL_IP_ROUTER2] [MASQUE]
            tunnel source [INTERFACE_PHYSIQUE_WAN]
            tunnel destination [IP_PUBLIQUE_ROUTER1]
            tunnel mode gre ip

Vérification Tunnel

show ip interface tunnel[x]
